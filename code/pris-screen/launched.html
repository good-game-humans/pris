The life of American machines_

This is pris. I put her to the task of eternal rebuild. The window above shows a live stream of her going about this task. The scrolling lines are the commands she is running, followed by the output of the commands.

She is rebuilding herself from bare metal. The rebuild process consists of downloading her source code (freely-available from various sites on the internet), then compiling the source code into her operating system and programs. The source code is a set of text files containing instructions for how to build the programs, and in computer parlance, the building of programs from source code is called compiling.

So pris is downloading the latest version of the Linux operating system code, as well as the latest versions of the rest of her, and compiling herself. When she is finished (after several days) she is in a pristine state. There isn't much time to enjoy her new digs because I give her a day to rest, then she reboots and begins the rebuild process anew.
