The life of American machines_

This is pris. I put her to the task of eternal rebuild. The window above shows a live stream of her going about this task. The scrolling lines are the commands she is running, followed by the output of the commands.

She is rebuilding herself from bare metal. This is an arduous and time-consuming process, especially for an older machine like pris. The rebuild process consists of downloading her source code (freely-available from various sites on the Net), then compiling the source code into her operating system and programs. The source code is simply a set of text files containing instructions for how to build the programs, and in computer parlance, the building of binary programs from source code is called compiling.

So pris is downloading the latest version of the Linux operating system code, as well as the latest versions of the rest of her, and compiling herself. When she is finished (after several days) she is in a shiny new state: she's got a fresh web server, new code libraries, assorted Python modules, and much more. There isn't much time to enjoy her new digs because I give her a day to rest, then she reboots and begins the rebuild process anew.
